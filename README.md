# Hospital Management System

A robust backend application designed to streamline hospital operations, manage department workflows, and handle secure data transactions. This project implements clean architecture principles to separate database logic from client data transfers.

## 🛠️ Tech Stack

| Technology | Purpose |
| :--- | :--- |
| **.NET 8 / C#** | Core application framework and backend logic |
| **Microsoft SQL Server** | Relational database management system (RDBMS) |
| **Entity Framework Core** | Object-Relational Mapper (ORM) for data tracking |
| **Git & GitHub** | Version control and feature-branch workflow |

## 🚀 Key Features Built & Implemented

* **Clean Data Architecture:** Utilizes **Data Transfer Objects (DTOs)** to ensure secure, isolated data boundaries between database entities and the API endpoints.
* **Department Workflows:** Supports department segregation and nurse/doctor tracking mechanisms.
* **Safe Version Deployment:** Developed entirely using a professional **Git branching strategy** (`feature/*` sandboxes) to guarantee a pristine, bug-free production-ready `main` branch.

## 📋 Prerequisites

To run this project locally, ensure you have the following installed:
* **.NET 8 SDK**
* SQL Server Management Studio (SSMS)
* Visual Studio
